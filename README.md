# Real-Time Chat Website

A web-based chat application built with Go, PostgreSQL, and WebSocket.

## Technology Stack

- **Backend:** Go, Gin Web Framework, WebSocket
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Database:** PostgreSQL
- **Authentication:** JWT + bcrypt
